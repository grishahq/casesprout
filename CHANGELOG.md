# Changelog

## 0.1.0a1 — 2026-10-25 — alpha

Independent CaseSprout fork based on Apache Burr commit `8bfd72689f1fbba4e858f7440dc77b764cd653b9`.

- Preserve Burr runtime, persistence, trace viewer source, history and licensing.
- Add deterministic batch path/error selection, exact duplicate counts and observed coverage reports.
- Add recursive named-field redaction and explicit independent expectation approval.
- Export JSON fixtures, runnable pytest and static HTML reports through trusted adapters.
- Include an offline real-Burr support demo with intentionally wrong historical output, independently specified policy, three injected regressions and equal-budget seeded random comparison.
- Include contract tests, focused upstream tests, clean artifact verification, review record and launch assets.

Limits: alpha; complete single-invocation local JSON traces only; exact outcome assertions; no automatic oracle, browser review UI, hosted service or PyPI publication. Key redaction is not anonymization. v0.2 targets review UI and CI comparison; v0.3 will add a format based on feedback.
